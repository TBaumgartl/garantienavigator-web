Support

Fragen, Fehler oder Wünsche? Schreib mir eine E-Mail an tbaumgartl@t-online.de. Ich antworte in der Regel innerhalb weniger Tage.

Hilfreich in deiner Nachricht:

  • Die Version der App (in der App unter Profil, Info, Version)
  • Dein iPhone-Modell und die iOS-Version
  • Was du gemacht hast und was stattdessen passiert ist, gern mit einem Bildschirmfoto

Häufige Fragen

Wie sichere ich meine Daten?

Deine Geräte, Belege und Fotos liegen nur auf deinem Gerät. Öffne in der App Profil, klappe die Kachel Daten auf und tippe auf Backup erstellen. Speichere die Datei zum Beispiel in iCloud Drive oder in der Dateien-App. Auf einem neuen Gerät holst du sie mit Backup wiederherstellen zurück.

Was passiert, wenn ich die App lösche?

Mit der App werden auch die Geräte, Belege und Fotos auf dem Gerät gelöscht. Erstelle vorher ein Backup (siehe oben). Dein Guthaben an KI-Scans bleibt erhalten, weil es auf dem Server liegt.

Wie funktionieren die KI-Scans?

Zwei KI-Scans sind einmalig gratis. Weitere kaufst du unter Profil, KI-Scans als Paket mit 50, 150 oder 300 Scans. Die Scans verfallen nicht, es gibt kein Abo. Ein Scan kostet ein Guthaben. Liefert die KI keine Antwort, wird nichts abgebucht.

Ich habe das Handy gewechselt. Wie bekomme ich mein Guthaben?

Öffne auf dem alten Gerät Profil, KI-Scans und tippe auf Meinen Code anzeigen. Kopiere den Code, öffne auf dem neuen Gerät dieselbe Seite und füge ihn bei Code übernehmen ein. Gib den Code an niemanden weiter: Wer ihn kennt, kann das Guthaben nutzen. Nutzt du auf beiden Geräten dieselbe Apple-ID mit iCloud-Schlüsselbund, wird die Kennung meist automatisch übernommen.

Mein Kauf wurde nicht gutgeschrieben.

Schließe die App ganz und öffne sie neu. Die App sendet den Kauf beim Start erneut an den Server. Steht das Guthaben danach immer noch nicht da, schreib mir mit dem Kaufdatum und der Bestellnummer aus der Quittung von Apple.

Wie bekomme ich einen Kauf erstattet?

Käufe wickelt Apple ab. Eine Erstattung beantragst du bei Apple unter reportaproblem.apple.com.

Wie lösche ich meine Daten beim Server?

Auf dem Server liegen nur eine zufällige Kennung, dein Guthaben und technische Angaben zu Käufen. Schreib mir eine E-Mail und nenne deinen Code (Profil, KI-Scans, Meinen Code anzeigen). Ich lösche die Daten dann. Das Guthaben ist danach weg.

Wo finde ich Datenschutz und Impressum?
